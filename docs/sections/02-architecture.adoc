== Architecture

System overview: what the pieces are, how operands flow in,
how results flow out, and where each piece lives in the tree.

=== System overview

The two paths are deliberately asymmetric:
input is pin-bound and streaming; the core itself is a fast
2-stage pipeline. A 4-cycle counter (`state_cnt`) owns the asymmetry:
four input bytes per MAC at the pins, two output phases for
the 32-bit result. The core latency is 2 cycles; the pin
throughput is 1 MAC / 4 cycles.

=== Pipeline stages

.The two stages inside the core
image::mac-stages.svg[Stage 1 multiplies two BF16 operands into an FP32 product. Stage 2 adds that product into the accumulator.,width=800]

Splitting multiply and accumulate buys a clean 20 ns budget
per phase at the 50 MHz target, instead of one giant
combinational MAC through the 32-bit adder and normalization path.
