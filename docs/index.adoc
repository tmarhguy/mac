== A multiply-accumulate unit

This block does one job: multiply two 16-bit brain-float numbers and add the product into a 32-bit floating-point total. That multiply-accumulate step is the inner loop of neural-network math. Brain float (BFloat16) keeps the range of a 32-bit float and throws away the extra precision. The layout targets the open SkyWater 130 nm process, for submission to Tiny Tapeout 7.

=== About this manual

This is the detailed technical reference for the project.
It is the companion to the concise, GitHub-facing `README.md`:

* `README.md` — project identity, status, and quick start.
* `docs/` (this manual) — architecture, interfaces, verification, and
implementation detail in engineering-manual style.

Conventions used throughout:

* `monospace` marks commands, file paths, identifiers, and literals.
* BF16 means 1 sign + 8 exponent + 7 mantissa bits; FP32 means IEEE-754
single precision. Bit fields are written `a[15]`, `a[14:7]`, `a[6:0]`.
* Unmeasured values are written as `TBD (unmeasured)` — never silently estimated.
* Normative pin and format detail lives alongside this manual
as Markdown (`docs/*.md`, `info.yaml`) and is linked, not duplicated.

TIP: Start with <<introduction,Introduction>> for scope and reading order,
then <<architecture,Architecture>> for the system overview.
